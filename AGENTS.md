# HanaPure Website: Codex instructions

- Work only in this repository. Check the path, branch, `git status`, and recent commits before changing files. Treat tracked code and Git history as the source of truth for implementation status.
- Read `docs/HanaPure_Website_Project_Handoff.md` for current state and confirmed direction, and `docs/MASTER_PLAN.md` for the roadmap. Plans are not evidence that a feature exists.
- This project uses Next.js 16 App Router, React 19, TypeScript, and Tailwind CSS 4. Before writing application code, read the relevant guide in `node_modules/next/dist/docs/`; this installed Next.js version may differ from familiar APIs and conventions. Heed deprecation notices.
- Preserve the existing website foundation and white/warm-white/beige/dark color system. Keep the website and HanaPure ERP as separate projects, with future integration in mind.
- Make scoped, reviewable changes. Consider mobile layouts from the start and involve LP in important UX, brand presentation, and customer-facing copy decisions. Verify changes before reporting completion.
- Do not pull, install dependencies, run migrations, commit, push, or change branches unless the current task authorizes it. Never overwrite unrelated local work.
